# 新闻关键词与手动大模型校准

日期：2026-10-06。适用：独立智能体 `redbook_agent`。

## 问题与目标

本地解析器用固定的新闻提示词构造任务，丢失了用户指定的关键词；界面只有确认执行，2026-10-03 的大模型任务识别设计尚未编码。本次补齐识别、比较、采用及执行参数传递。

默认发送继续本地识别，不调用模型。支持“生成5条每日新闻，关键词：伊朗、关税、芯片”等显式关键词，以及“关于……的每日新闻”“围绕……生成每日新闻”等常用表达。关键词显示在对应栏目下，写入该栏目实际使用的 `prompt`，其他栏目的关键词互不污染。关键词是选题检索条件，不是已经核实的新闻事实；日期、来源和查重仍由原工作流核验。

## 交互

右侧本次计划标题下显示识别来源，并提供带 BrainCircuit 图标的“大模型校准”次级按钮。正常计划和本地未识别的任务均可校准，已开始执行的计划不能修改。按钮绑定计划对应的原始用户消息，不能误用最新的进度询问。

点击后显示模型和等待状态；成功后在该区域展示当前计划与候选的数量、关键词、选题要求、交付方式、速度模式及评分设置差异。用户选择“保留当前计划”或“采用校准计划”。采用只更新待执行计划；生成与上传仍由“确认并执行”启动。识别失败显示具体原因并保留原计划。刷新可恢复候选；新任务、模型设置改变后拒绝采用过期结果。

## 实施契约

- 本地与模型结果统一为栏目任务：`kind/count/title/keywords/topic_brief/prompt/evaluation_viewpoint/lookback_days`。`prompt` 是既有 CLI/AgentJob 消费的字段，新字段用于显示与追踪。
- 校准采用 `task-recognition.v2`，在 v1 的 `jobs` 中增加 `keywords` 字符串数组。关键词应来自原文，不擅自扩展事实。每个实质要求保留对应原文证据。
- API：创建识别 `POST /api/conversations/{id}/task-recognitions`；查询 `GET .../{recognition_id}`；采用 `POST .../{recognition_id}/adopt`；放弃 `POST .../{recognition_id}/discard`。
- 使用现有主控角色模型；通过不可变配置直接发送一次 chat 请求，输出上限4096 tokens、60秒网络超时、无自动重试/模型降级。识别不调用新闻、生图、浏览器或额度同步。
- 严格校验 JSON、枚举、数量和证据。模型没有执行/批准权限，不允许通过候选扩大到公开发布、删除、付费降级或取消事实/日期检查。
- 实际支持的选项才落地；明确的硬性配比若执行器只有软偏好，应提示能力缺口。集合稿内部条目不能误变成多篇稿件。
- 识别记录存入现有 PostgreSQL 会话 payload 的 `task_recognitions`，复用修订号与乐观锁。本次不新增表，生产数据库不可用时直接报错。请求、状态和候选采用均用短事务，模型等待期间不持有事务。
- 单个后端一次仅接受一个校准，生成运行中拒绝校准；校准期间拒绝启动执行。幂等键绑定原始消息和基础计划，重复请求不重复调用模型。服务重启将未完成识别标为中断，手动重试。
- 冻结计划保存来源、关键词、要求和本次设置；CLI通过实际 `prompt` 读取关键词，续跑沿用冻结文件。

## 验证

覆盖本地多关键词/栏目隔离/无任务原文保留；校准调用次数、超时/限流/坏JSON；采用不执行、双击幂等、过期与跨会话拒绝；执行文件与AgentJob实际读取关键词；桌面/手机按钮、对比、采用和失败反馈。最后用真实MiniMax订阅做一次只识别的验证，不启动内容生成或平台写入。

调用图绑定：`redbook_auto_agent`，`E:/AI/codex/redbook_agent`。`_parse_agent_message`、`append_agent_message`、`execute_agent_plan` 为 LOW；前端 App 和 FastAPI 路由属于静态图不能跟踪的框架入口，已通过入口文件、路由装饰器和前端请求定位实际消费者。

## 实施与验证结果

实现于独立智能体后端、React前端及仓库内 `tools/redbook_tools`；未改旧工作流目录。README已增加关键词示例和校准操作说明。

需求映射的允许目标包含 `job.keywords`，栏目范围为明确枚举。真实 MiniMax 实测曾揭示该字段遗漏；补齐后校准通过，不通过放宽JSON校验处理。后端另行拒绝模型改变明确的阿拉伯数字新闻篇数、遗漏显式关键词，或把“不上传”改为平台保存。

- 回归：`tests` 加工具包 `test_web_gui.py`、`test_editorial_agent.py`、`test_editorial_agent_retention.py`，187项通过、1项跳过，58.94秒；已有3条依赖弃用警告。
- 前端：TypeScript检查与Vite构建通过；独立无头浏览器测试覆盖按钮等待、候选比较、采用不执行、刷新恢复、保留原计划、失败及待澄清状态。1440、390、760像素宽度验证无页面横向溢出；截图在运行区 `data/tmp/pytest-task-calibration-final/`。使用临时独立浏览器上下文，不接触用户默认浏览器或平台profile。
- 真实 MiniMax-M3 订阅校准：6.094秒，正确保留5条每日新闻、伊朗/关税/芯片、速度优先、不同步额度、不上传、关闭图片评分硬门槛；候选采用并存入PostgreSQL，重复采用返回同一计划，对话运行记录仍为空。

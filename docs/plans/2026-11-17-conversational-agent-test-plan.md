# 对话智能体实施与验收计划

对应设计：`2026-11-17-conversational-agent-design.md`。

## 验收矩阵

| 要求 | 必须取得的证据 |
| --- | --- |
| 真实开源智能体 | 实际导入并运行 LangChain create_agent，模型返回 tool_calls、工具结果进入下一次模型请求；不得测试替身冒充框架 |
| 模型兼容 | 原有MiniMax订阅和自定义模型适配不自动切换；Chat/Responses/Anthropic工具消息编解码和角色绑定回归 |
| 真实持久化 | PostgreSQL临时隔离数据中形成原生检查点；重建执行进程后同一thread继续；生产不降级内存/SQLite |
| 工具缺失与权限 | 关闭工具时不执行，出现具名申请；拒绝后执行次数为0；审批只能开启请求范围，不能提升全局禁用权限 |
| 实时暂停 | 睡眠模型请求、资源等待、采集/单篇生成、排队上传分别测试；控制HTTP及时返回，目标子进程有界退出；其他进程不受影响 |
| 取消 | 重复取消幂等；已取消执行不能被继续按钮复活；已有稿件和草稿回执保留 |
| 对话连续性 | 用户补充要求进入同一上下文；已有成功产物不重做，缺口由模型选择工具补齐 |
| 非无限重试 | 同一错误第二次进入等待用户；换关键词不能清掉失败计数；额度/权限/平台限制第一次即中断 |
| 写入安全 | 平台串行、稿件版本去重、未知结果不重放；图片评分参考模式不会转成硬门槛 |
| 五栏目 | 新闻、AI讯息、我去、AI福利、全球图各有真实工具边界；不再通过一个旧批处理命令实现默认聊天 |
| GUI | 真实浏览器桌面和手机截图：消息、实时状态、授权允许/拒绝、暂停/取消/恢复、刷新和切换会话不串数据 |
| 原功能保留 | 旧工作流/手工CLI/模型平台/能力中心/知识库/专用profile配置与原数据不删除、不迁移破坏 |

## 测试顺序

1. 先记录旧版取消失败、版本不兼容和当前dirty文件；新增测试必须有失败证据。
2. 用本地fake ChatModel或本地HTTP模型验证真实框架循环及审批中断，真实PG独立schema，禁止生产库模拟成功。
3. 用隔离无网络Python进程验证stop、并发、进程身份和资源清理；不得为测试杀真实用户服务。
4. 用API夹具测试UI写操作，真实前端静态资源截图；验证安全校验及幂等，不写平台。
5. 主控实际MiniMax只读测试可在用户已授权订阅下单独执行；新生成或上传测试应独立说明范围，不把fake结果当作平台回执。
6. 父智能体复核全部改动与报告，确认正式服务加载的版本、生产任务无意外新增和原有稿件仍在。

## 发布门槛

没有未解决的授权、误写、不可停止、重复上传等高风险失败。依赖不兼容或PG不可用必须明确停止启动。不得为了通过测试回退到旧正则任务脚本，也不得降低时效性和真实性校验。

测试日志、截图、临时环境和下载缓存全部位于 E 盘 data 下；不上传密钥、浏览器profile或数据库连接信息。生产的 `redbook_runtime` 内容和用户其他任务不作为破坏性测试夹具。

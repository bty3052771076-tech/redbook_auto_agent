# 独立智能体实时进度与对话反馈

## 目标和边界

将现有运行事件转为使用者可读的中文进度，回答当前在做什么、完成多少、用了多久、失败原因以及下一步。仅改独立智能体的展示与只读进度接口，不改生成或上传策略，不增加模型调用、自动重传或公开发布。

## 数据与后端

- `/api/runs/{id}` 增加 `activity`：中文状态、当前栏目和阶段、耗时、最近动态、各栏目目标/产出/审查/平台保存/回读数量、时间线、问题与建议。
- 依据本次运行 stdout 事件、原子检查点和已有本地平台回读记录。上传与回读分别统计；未知数量显示待记录，不推测百分比、剩余时间或成功。
- 使用稿件 ID 去重；恢复与重复事件不得重复计数。多栏目部分完成保留成功结果，指出失败栏目。历史运行只有日志时不得声称已上传。
- 进度追问只保存用户消息与事实状态回复到既有 PostgreSQL 会话，不创建计划或提交执行。新任务仍然需要确认。
- 不更改原有脚本接口；旧 GitNexus 索引不覆盖独立目录，影响检查需结合实际前后端调用和测试确认。

## 前端

- 在对话中展示独立的运行播报：当前动作、耗时、数量、栏目列表及最近动态；失败时显示具体原因和可操作建议。
- “最近一次运行”改为中文摘要；运行记录展示同样的详细进度，原始技术日志默认折叠。
- 请求轮询不重叠，切换任务取消旧结果，读取失败保留最后状态并自动重连。刷新恢复上次对话；任务结束后更新会话和记录。
- 与现有青绿色工作界面保持一致；移动端堆叠，长文本换行，不嵌套装饰性卡片。

## 验证

1. 单测覆盖运行阶段、真实数量、回读区别、重试去重、部分完成、本地交付、缺失检查点、中断和只读进度问答。
2. API 测试证明追问不创建计划或调用模型；权限/来源校验保持不变。
3. TypeScript 与 Vite 构建；浏览器验证持续更新、刷新恢复、网络恢复、阶段结束、追问和原始日志折叠；桌面/移动端截图及溢出检查。
4. 使用现有历史运行作真实只读检查，不为界面测试重新生成或上传稿件。

## 实施与验证结果

已完成进度格式化、只读状态问答、对话运行播报、中文运行摘要、自动重连及刷新恢复。增加旧后台兼容展示，避免为了载入新接口而中止正在生成的稿件。

- 29 项新增相关测试通过，包含真实 E 盘 PostgreSQL 问答持久化及 3 项浏览器场景。原有 8 项后端测试也通过。
- TypeScript 校验与 Vite 生产构建通过。浏览器未出现脚本错误；390/760 像素移动端无横向溢出，桌面截图已检查。
- 模拟网络失败后状态保留且自动重连；追问没有产生新计划或提交执行；运行完成后按钮不再允许重复确认。
- 实际运行与历史部分完成记录已只读核对，数量来自现有记录，没有重新生成或上传。历史记录仍可能缺少部分回读证据，界面如实显示未确认，不补造成功。
- 截图保存在 `E:\AI\codex\redbook_runtime\data\tests\20261001-live-progress`，临时文件在运行区 `data/tmp`，不进入项目根目录。
- 当前服务仍有生成任务，新后台未强行热替换。该任务结束后需重启 `Start-Agent.cmd`，再刷新页面启用完整接口。

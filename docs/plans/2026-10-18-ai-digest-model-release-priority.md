## 原因与修复

1. 原通用新闻列表解析器先于日志正文解析执行，将日期锚点识别为新闻卡片并提前返回。增加标准库HTMLParser日期分节解析：日期标题、更新标题、该条正文、锚点一一对应，忽略导航和侧栏，不借页面最新日期改写旧版事件。
2. 官方英文候选关键词漏掉DeepSeek；版本升级标题中的Update未被明确模型发布识别。补齐厂商关键词与明确版本升级识别，保留服务迁移/下线通知区分。
3. 原排序先按模型发布排序，但后续日期分组可能把同日普通更新插到另一日模型发布前。分组键保留模型发布优先层级，再比较日期、类别和厂商多样性。
4. 模型历史键遗漏1017等显式日期版号。保留命名模型中的4/8位修订号；通用product字段不能盖掉标题明确的同一模型修订号。旧版本不误伤新版，同一新版跨链接仍查重。

## 边界

- 同步修改原工作流和独立智能体的内置工具，仅涉及AI采集与排序；保留两天自然日窗口、事实核验、查重、来源数量限制，无新增硬配额。
- 不把DeepSeek或某一天的事件硬编码为必选；不为数量混入旧闻，也不保证上游网络永远可用。
- 模型发布与明确版本升级优先，一般工具/工程更新随后；未修改现有传闻真实性检查规则。
- 不安装依赖、不修改Key或付费策略、不重启正式服务、不修改已生成稿件，不生成或上传新稿。

# 能力中心：页面、交互与验收设计

日期：2026-10-08。状态：设计与验收规格，不是验收通过报告；当前工作树部分实现情况见[2026-10-09 复核](2026-10-09-agent-capability-management-design-review.md)。  
主设计：[工具、MCP、SKILLS、记忆与知识库](2026-10-08-agent-capability-management-design.md)。

## 1. 页面位置和视觉规则

沿用当前独立智能体的 React/Vite 界面、Lucide 图标和样式：224 px 左侧导航、64 px 顶栏、白色工作区、青绿色主操作、灰色分隔、橙红故障提示。保留现有字体，字距 0，常规字号 13–14 px，页面标题 24 px，抽屉标题 18–19 px。常规组件圆角 4–6 px。

左侧“连接与模型”之后增加 Puzzle 图标的“能力中心”。页面以页签、筛选栏、表格和详情抽屉组织，减少大卡片，避免每类资源占据一个侧栏一级入口。

全局页签：概览 / 工具 / MCP / SKILLS / 记忆与知识库 / 调用与变更。页签切换保留筛选、分页和选中项；URL 使用可恢复的参数或 hash，例如 `#capabilities/mcp/<id>`，不只保存在 React 临时 state 中。

刷新、查看详情、复制 ID 等使用图标并提供 tooltip/aria-label；启停用 Switch；off/auto/manual 用分段控件；传输方式和筛选项用 Select；添加、导入、检测等清晰命令用图标+文字按钮。

## 2. 概览页

```text
既有侧栏         能力中心                          [刷新状态]
                概览  工具  MCP  SKILLS  记忆与知识库  调用与变更
                -------------------------------------------------
                工具 可用/登记    MCP 可用/配置    技能 已启用/安装
                PostgreSQL 已连接    索引 已就绪    最后检查时间
                -------------------------------------------------
                待处理
                MCP 本地服务：Python 路径不存在          [查看连接]
                SKILLS：尚未导入                         [导入技能]
                -------------------------------------------------
                最近调用
                时间 | 能力 | 所属任务 | 结果 | 耗时 | [详情]
                -------------------------------------------------
                运行环境
                应用目录 / 数据目录 / Python / profile / 数据命名空间
```

指标是窄信息带，点击可用数进入对应筛选。统计口径为顶级登记工具；子调用计入流水，不重复算能力数量。

待处理项排序：阻塞当前任务、配置失效、未知/过期检测、其他建议。一个 MCP 不可用不让其他栏目消失。“尚未导入技能”使用空态样式，不用红色故障。

环境区默认折叠，点击展开显示完整路径、更新时间和复制图标。小红书字段包括实际 user-data-dir、profile-directory、当前账号已验证/未验证及核验时间；路径已配置不能等同于登录成功。

数据库统计按本次核查示例应显示“文档 4,390 / 已索引 4,372 / 空文本跳过 18 / 待索引 0”，旁标快照时间。产品实现使用实时值。

## 3. 工具页

```text
工具                               [检查所选]
[搜索名称或用途] [来源 v] [能力组 v] [状态 v]
名称及用途       来源      状态       使用范围   开关     最近调用
生成每日新闻     内置      就绪       工作流     [开]     任务链接
保存平台草稿     内置      待检测     工作流     [开]     任务链接
检索新闻         MCP       不可用     准备阶段   [开]     错误链接
```

点击任意行打开右侧详情，不直接运行工具。抽屉固定显示：

1. 名称、来源、版本、配置信息和最近检查时间。
2. 作用与阶段：如“在候选材料准备时检索相关新闻”。
3. 输入/输出：先展示可理解的字段，JSON schema 在高级详情中。
4. 依赖：模型、数据库、连接、profile；依赖名称可跳转。
5. 影响：只读、本地写入、模型额度、平台草稿写入等实际标识。
6. 本次使用与最近调用：点击进入流水详情。
7. 参数与生效范围：仅适配器支持的字段可编辑。

停用示例：关闭“保存平台草稿”后，新的草稿上传计划显示“保存草稿工具已停用”，允许用户改为仅生成或重新启用；不能仍显示“可以上传”到执行后才失败。

有运行任务时，普通开关显示“新任务已停用；1 个运行任务仍使用 v3”。旁边菜单提供独立的“停止后续调用”，列出受影响任务与在途调用情况。平台上传并发值固定显示 1，不提供拖动控件。

工具“试运行”与“检查可用性”分开。生成/上传类试运行展示精确输入、额度或写入影响，确认后仅执行该次操作；列表勾选批量检测不能变成批量生成。

## 4. MCP 页

### 4.1 主列表及添加抽屉

列表列：连接名称 / stdio或HTTP / 配置开关 / 健康与时间 / 工具数（已允许/已发现）/ 进程状态 / 最近错误。

顶部提供“添加连接”“导入配置”“检查所选”。行菜单提供编辑、检测、发现工具、查看日志、退役。敏感环境变量和 Header 显示“已配置”，不提供批量明文复制。

添加流程：

1. 选择本地 stdio 或 Streamable HTTP。
2. 本地填写 executable、参数列表、工作目录、明确需要的环境变量；HTTP 填写地址和认证引用。
3. 保存未启用连接，显示配置检查结果。
4. 点击“检测并发现工具”，异步显示传输、协议识别/必要握手、枚举阶段和实际协议版本。
5. 查看工具清单与 schema；选择允许阶段/权限后启用。

导入 JSON 只填写表单，必须显示未知/不支持字段。页面不得通过预览动作执行导入的启动命令。

### 4.2 可操作的错误

| 情况 | 展示 | 可用动作 |
| --- | --- | --- |
| 运行区找不到 Python | 具体缺失路径、正确应用解释器候选 | 编辑路径；测试候选路径；保存 |
| 启动成功但协议握手失败 | 阶段、耗时、退出码、脱敏 stderr | 查看日志；编辑参数；再次检测 |
| 需要代理但连接失败 | 本次网络策略、目标 host、超时阶段 | 修改该连接代理设置；检测 |
| 新增工具 | 新工具数及差异 | 查看并选择允许范围 |
| 工具 schema 改变 | 旧版与新版字段差异 | 采用新版；保留当前任务版本 |
| 服务未启动 | 按需启动/当前空闲 | 检测；不标成故障 |
| OAuth/SSE 未接入 | 明确不支持项 | 修改配置；不显示虚假的连接成功 |

“退出进程”仅对本程序拥有的 stdio 进程有效，运行中先停止后续调用并等待在途请求结束。不能按进程名称批量关闭用户的 Node、Python 或浏览器。

## 5. SKILLS 页

列表列：技能名称 / 描述 / 来源 / 版本 / 适用栏目 / 启用 / 最近加载。顶部“导入技能”和默认模式分段控件；缺少技能时显示可操作的导入入口及当前目录。

技能详情的页签：说明 / 引用文件 / 版本 / 使用记录。说明正文用 Markdown 安全渲染，HTML 和脚本不执行；图片和资源只从已批准技能目录解析。

导入预览须展示名称冲突、文件数量、总大小、正文 hash、未支持语法和附带脚本。提交按钮仅在预览通过且文件 hash 未变化时可用。导入后的默认模式不自动从关闭切换成自动。

手动编辑内置技能时“创建副本”；编辑用户技能时保存新版本。引用文件也计入版本 hash，避免只改附件却仍显示旧版本。

正常状态示例：已启用但本次未选中；已选但尚未加载；已加载 1 项正文并读取 1 个附件。界面不把“已加载”描述成“已保证遵循”。

## 6. 记忆与知识库页

二级页签：长期偏好 / 资料库 / 对话上下文 / 任务断点。

### 6.1 长期偏好

列表：内容 / 作用域 / 来源 / 状态 / 有效期 / 最近使用。顶部搜索、筛选和“添加偏好”。来源必须可跳到用户消息、人工新增记录或被确认的候选。

添加/编辑抽屉：内容、作用域、关联栏目/对话、有效期、变更原因。保存预览说明受影响的后续任务。对于冲突偏好，展示旧值、新值、各自来源与生效范围。

“停用”与“忘记”分开：停用保留可重新启用版本；忘记进一步使派生上下文引用失效，显示处理进度。两者均不删除用户的历史稿件或图片。

### 6.2 资料库

```text
资料库                     [测试检索] [增量索引]
[搜索原文] [类型] [用途] [日期] [索引状态] [命名空间]
标题     来源/类型    原文日期   用途       索引状态    更新于
```

点击记录查看正文、原始来源链接、采集时间、索引片段、当前用途和修订历史。纠错注释与原文分栏；不能把人工纠正直接覆盖到来源原文。

测试检索使用抽屉：查询词、用途、namespace → 命中片段、匹配原因、排序分数和耗时。分数标“检索排序分数”，不标“可信度”。无匹配、无可用索引、嵌入模型缺失、数据库断开分别说明。

“排除检索”让用户明确选用途。默认可以排除证据/风格参考并保留历史查重，避免误删已发记录的查重作用。大批量操作展示数量和用途差异。

### 6.3 对话上下文

顶部选择对话。主体左侧显示摘要及约束来源，右侧显示摘要覆盖范围和保留消息；下方列历史压缩版本与模型。

提供“查看本次实际上下文”“生成压缩摘要”“记录纠正”。压缩操作显示实际主控模型和进行中状态。无收益显示“无需替换”，冲突显示“对话已有新消息，请刷新后重试”。

“上下文策略”抽屉允许选择自动/仅手动、阈值和近期保留量。历史已保存、当前已选入、实际发送至模型分别给出范围。没有摘要时不能把仅展示的最近消息描述为完整历史；当前适配器未注入的内容显示“尚未用于生成”。

“查看实际上下文”使用正常输入摘要及引用，不展示模型私有推理过程。缺少历史调用记录时写“未记录”，不能根据最新配置猜测历史任务用过什么。

### 6.4 任务断点

复用运行记录信息，以任务为单位展示目标数量、已生成、已审核、已保存草稿、需要继续的步骤以及工具/模型/技能版本。点击“继续任务”进入既有恢复流程。

能力退役或版本缺失时，展示具体差异和受影响步骤；已完成产物继续保留。此页不提供手动修改已上传数量或把状态改成成功的控件。

## 7. 对话页联动

```text
本次计划
  每日新闻 10条
  每日AI讯息 1条

本次能力                                      [调整]
  工具     新闻检索、生成、审稿、草稿保存等
  SKILLS   [关闭 | 自动 | 手动]    已选 2项
  记忆     3条偏好 / 8条历史匹配                 [查看]
  模型     当前主控 / 写稿 / 生图绑定
  浏览器   runtime/.../chrome-profile · Default [详情]
  检查     1项必需依赖不可用                    [处理]

执行边界：保存草稿
[确认并执行]
```

该线框中的计数仅说明布局，实际数据取自本次预检或运行记录。历史匹配尚未检索时显示“执行时检索”，不预造 8 条结果。

“调整”修改本次未执行计划，保留用户手动关键词、数量和模型校准结果。进入执行后显示只读快照；修改全局配置不偷偷改写本次计划。

运行播报使用具体事实，例如“正在调用新闻检索”“已加载模型发布核验技能”“本次查重命中 4 篇旧稿，排除 2 个重复事件”“草稿已保存，读回正文一致”。来源为结构化事件，不能靠生成一句成功文案替代调用结果。

对话详情中的能力名称可点击打开能力中心详情，返回后仍定位原任务。未记录的旧任务显示“该版本未采集”，不补造历史。

## 8. 调用与变更

调用列表：时间 / 工具 / 主任务 / 调用阶段 / 结果 / 排队时长 / 执行时长 / 重试次数。筛选包含任务、工具、结果、诊断或业务调用。

详情展示输入摘要、实际工具及配置版本、模型（如适用）、profile（如适用）、使用的记忆/技能引用、结果摘要、产物/证据链接和错误。原始大日志按需展开，持续脱敏。

父调用可以展开子调用；总墙钟时间独立展示，不能累加并行子调用伪造总耗时。统计提供样本量和时间窗。变更页签记录“谁在什么入口把什么资源从哪个版本改成哪个版本”，允许查看差异和退役原因。

## 9. 窄屏、无障碍和异常状态

- 桌面宽度至少 1280 时使用列表+380–440 px 详情区；1024–1279 使用覆盖抽屉；更窄使用全屏详情，保留返回入口。
- 390 px 手机视口只显示名称、状态、开关等关键列，其余进入详情；URL、路径和英文工具 ID 允许换行。
- 页签可横向滚动，操作栏可换行，不能缩小到无法点击。图标按钮触控区域至少 40 px；键盘可达、焦点可见。
- 抽屉关闭恢复到原行；未保存修改离开时提示保留/放弃；ESC 不取消已提交的后台任务。
- 状态同时使用文字和图标，不只靠颜色。数据库离线时保留可读静态目录与时间戳，不让全页加载失败。
- 首屏不加载全部技能正文和历史文档，列表错误和详情错误各自恢复。

## 10. 实施验收场景

本表是未来编码后的测试计划，本次没有执行。生产实机验收使用独立命名空间、测试资源和小规模任务；涉及模型和平台的试运行须在明确的测试任务中执行，不由打开管理页触发。

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| A01 | 目录列出内置工具、MCP、技能 | ID 稳定，无重复伪计数；空目录明确；未接入显示真实状态 |
| A02 | 打开/刷新能力中心 | 不调用模型、不打开浏览器、不创建 MCP 进程、不生成/上传 |
| A03 | 一个 MCP 构造失败 | 仅对应连接报具体路径错误，其余目录仍可用 |
| A04 | 修正当前解释器配置 | 用应用 .venv、运行区 cwd 正常启动；不创建 C 盘依赖或第二个数据库 |
| A05 | 停用工具后经 GUI 和智能体 CLI 调用 | 两个入口均遵守策略；内部子调用不能绕过 |
| A06 | 任务运行中修改默认配置 | 当前任务仍引用冻结版本，新任务使用新版本，UI 清楚标识 |
| A07 | 停止后续调用 | 在途外部操作核对结果，后续调用被阻止，保留已完成产物 |
| A08 | 发布或删除工具试图借 MCP/Skill 越权 | 仍受实际授权及独立界面执行边界约束 |
| M01 | stdio 假服务及本地真实只读服务 | 协议识别、目录、调用各有证据，不把仅连接成功算作调用成功 |
| M02 | HTTP 服务成功、401、超时、协议错误 | 原因分开显示，敏感 Header 不返回前端/日志 |
| M03 | 新增/移除工具或 schema 改变 | 显示差异，新工具未自动授权；旧任务不静默换版本 |
| M04 | 两个服务暴露同名工具 | server_id 命名空间正确，无串调用 |
| M05 | 自定义只读工具绑定准备阶段 | 实际在测试任务中被选择并调用，输入/结果/用途可追踪 |
| M06 | 按需生命周期 | 同任务适当复用；空闲或任务结束释放；不杀其他软件进程 |
| M07 | 2026-07-28与旧版服务、分页未完成 | 使用实际兼容协议，不强制所有服务initialize；目录不完整时不误判工具删除 |
| S01 | 有效技能导入、预览、启用、手动选择 | 正文与资源 hash 可核对，任务记录实际加载版本 |
| S02 | 关闭、自动、手动模式 | 关闭不注入；自动可匹配中文栏目；手动最多3项且不擅换 |
| S03 | 同名版本、非法 frontmatter、路径穿越/重解析点 | 不覆盖旧技能、不越界、不留下已激活的半导入目录 |
| S04 | 任务中更新或退役技能 | 当前已冻结版本可复现，新任务按新配置，删除引用关系明确 |
| S05 | SKILL 要求执行命令/添加权限 | 仅加载正文不能触发脚本或扩大工具权限 |
| K01 | PG 真实读写及重启 | 记忆、版本、上下文、调用记录持久化；不使用生产内存/文件降级 |
| K02 | 4,390文档/4,372索引/18空文本文档样例 | 空文本计跳过，待索引0；不显示18条失败 |
| K03 | 文档内容改变后增量索引 | 新版本检索正确，旧片段不混入当前版本结果 |
| K04 | 指定用途排除一个文档 | 检索 SQL 实际排除；保留的查重用途仍能命中 |
| K05 | 不同 namespace 的同名记录 | 入库、检索、索引、详情一致隔离；历史local数据不被自动错绑 |
| K06 | 偏好作用域和本次明确要求冲突 | 本次要求优先，显示被覆盖的旧偏好及来源 |
| K07 | 忘记一条已进摘要的偏好 | 后续上下文不从摘要/缓存重新注入，原始稿件和图片仍存在 |
| C01 | 低于阈值、摘要无收益、正常压缩 | 区分无需压缩/无收益/成功；原消息保留；版本准确 |

### 10.1 自动化与实机划分

自动化覆盖策略和版本、MCP 协议假服务、技能导入、PG 事务与 namespace、上下文失效、API 权限、前端状态及窄屏。PG 测试在独立测试库/namespace执行，禁止清空生产库。

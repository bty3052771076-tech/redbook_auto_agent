## 当前改动

1. 每日新闻首图初次审核后记录不可变身份对应的成绩，第二图更优或恢复第一图时不丢首图记录。
   `image_lineage` 只由初次新闻创建路径建立，不从当前图片猜测旧历史。
2. 首图统计在备选裁剪前计算，包含被淘汰稿件；按版本、已审、通过、失败、待审和未知身份分别计数。
   必须同时 `ok=true` 且有效分数至少 70 才计通过。统计保存在栏目 context 并输出进度日志。
3. PostgreSQL 逐篇快照恢复时，只对相同内容版本合并本地保存回执；相同首图身份的首审记录可补回，
   不用本地较旧快照覆盖已有审核。平台保存成功后立即提交逐篇 uploaded 快照。
4. 已完成 AI 资讯栏目恢复时执行已有 `stored_ai_digest_review_issues`，不能只看官网数量；
   检查有效替换链末端，避免旧问题祖先反复重开栏目。
5. 单项替换持久化祖先和内容版本，同时继承平台更新目标但不继承已保存状态。
   XHS 更新原草稿；目标异常或保存不确定不自动转为新增。
6. 同 ID 内容修订也优先更新其已有平台草稿。core 只信当前版本完成键，历史 ID 不再充当完成证据。
7. `--budget-minutes` 保留命令兼容，但帮助文字明确停用，CLI 执行配置恒定传 0。

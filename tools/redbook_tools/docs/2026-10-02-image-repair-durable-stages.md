# 图片修复逐阶段保留与无共享预算

## 本轮范围

只修改设计与代码，未执行测试、构建、模型请求、生产任务或平台上传。
新增用例是待执行的验收资产，不是已经通过的证据。

## 根因与局部修复

原有完整的两图择优缓存只能覆盖审核已经全部结束的情况。第二张图生成后、第二次审核完成前
如果退出，恢复时可能再次生图；首评原来只写本地文件，不能保证已进入逐篇 PostgreSQL 账本。

新 `image_repair` 记录绑定稿件 ID、正文、标题、话题、事件、评价视角、审核策略版本和非秘密审核配置。
第一张与第二张分别保存实际资产指纹、图片元数据及真实审核结果。快照不递归嵌套修复记录，
恢复只更换图片字段，不回滚稿件状态、平台回执或其他元数据。

| 阶段 | 必须持久化的内容 | 恢复行为 |
|---|---|---|
| `first_reviewed` | 第一张资产和首评 | 首评通过则直接复用；不通过时允许唯一一次重画 |
| `redraw_requested` | 在外部请求前预留的重画名额 | 已有不同的完整资产则接续审核；没有则保留首图并记录请求不确定，不再次提交重画 |
| `redraw_saved` | 第二张实际资产 | 只审第二张，不重复生成 |
| `second_reviewed` | 两张的完整审核结果 | 只选择较优图片，不调用模型 |
| `redraw_failed` | 重画失败证据 | 保留第一张及拒绝原因，不把失败当作通过 |
| `complete` | 选择结果 | 输入和实际文件一致时复用；文件或版本不一致则不能冒充有效证据 |

每次阶段变更先 `save_post`，随后通过原 `on_post_reviewed` 回调提交 `AgentArtifactStore`。
在本地图片保存与 PG 回调之间退出时，只允许合并有相同原始修图记录、相同内容键、
同一稿件和真实新图片字节的本地产物。任意本地正文改写不能覆盖数据库中的任务快照。

## 生图提示词 v4

同一次写稿调用生成完整 `image_event`，不新增提示词生成调用：

- 选择一个来源支持的可见时刻，明确主体、动作、地点或环境、空间关系和物体状态。
- 声明、警告、计划和提议只表现发言或讨论；未经核实的指控不画成已发生的行为。
- 未知外貌与环境使用概括示意，不声称是现场照片，不凭空加入制服、武器、伤亡等细节。
- 一个连续场景、少量主要主体、干净平涂，物体表面无文字、数字、标志和水印。
- 不重复整篇正文，不把评论隐喻转换为事故，不将多个新闻阶段拼贴。
- 修图只提供与实际缺陷对应的局部指示，不能嵌套整段旧提示或把审核建议当作新闻事实。

审核仍要求 `ok=true` 且得分至少 70。两张都不合格时补其他事件，不无限重画同一篇。
首图记录独立于最终选择；任何失败或未知候选均计入相应统计，不仅统计最终入选稿。
10 个最终入选的不同事件至少需要 6 张首图真实通过，才满足“大于一半”的验收目标。
**本轮没有实测，不能承诺该指标已达到或承诺固定提速比例。**

## 缓存与时间

审核缓存 v3 除真实图片字节、正文和事件外，增加预期场景、实际生图提示与非秘密审核配置；
修改这些输入必须使旧缓存失效。缓存不替代日期、来源、查重和平台写入核对。
两图完整记录同样验证当前场景、提示和图片，不能绕过缓存失效去恢复覆盖人工修订。
“预留请求后新增图片”的判断同时检查真实资产路径和字节，不把单纯元数据变化当作第二张已保存。

常规新闻采集不再给 `DailyNewsDiscovery` 传 180/900 秒的共享预算，使用
`NewsFetchSession.remaining_seconds=None`。1/2/3/5 日窗口、来源数量、查询轮次及单次请求超时仍然有界。
已有调用显式提供有限预算时，仅保留兼容能力；当前智能体/自动生成主链不启用该累计预算。
CLI 进度改为显示“不设共享采集预算，单次请求仍有超时保护”，不显示 `None 秒`。

持久保留继续使用 PostgreSQL；审图缓存和修图记录保存在稿件/逐篇账本中，本轮不部署 Redis。
Redis 若未来用于热点缓存，只能是可重建的加速层，不能成为断点恢复的唯一事实来源。
视觉请求入口另有进程内共享的两个许可：批量线程和内联单篇审核使用同一上限，
不是每个调用方各自获得两路请求。该边界不声称能取消已经进入供应商的请求。

## 待执行验收

`tests/test_image_repair_resume.py` 已编写但未执行，覆盖第二次审核中断、重画请求未知、
首评先提交、PG/本地窄窗口合并、恢复图片不回滚平台回执，以及三个新增缓存失效因素。
还需真实 PG 中断恢复、模型调用计数、原稿件与资产散列、平台串行上传回执和 10+1+1 单句任务验收。

远程调用返回与本地落盘之间仍不是跨介质原子事务：没有第二张保存证据时不重发该重画，
只能保留第一张并补充别的事件。不能声称外部 API 严格 exactly-once。
显式取消、缺额/凭据无效、数据库不可用、平台封禁或写入未知必须停止相应操作并保留证据；
“不中断补齐”不能解释成绕过平台限制或重复提交结果未知的写入。
